1. 设计基础 Prompt
============================================================

Create a single-page luxury alpine hospitality website for a contemporary mountain retreat called Alpine Retreat. The brand should feel quiet, architectural, cinematic, and highly editorial rather than sporty, rustic, or generic hotel marketing.

Visual identity:
- Build a high-altitude palette around warm snow white, mist white, glacier grey, natural stone, restrained alpine pine, and cinematic graphite.
- Use warm snow as the main light surface, deep graphite for full-bleed mountain scenes, muted pine as a subtle primary, and glacier grey as a cool mineral accent.
- Avoid bright greens, saturated oranges, glossy gold, and generic outdoor-adventure styling.

Typography:
- Use Fraunces at light weights for large editorial headings, hero wordmarks, and accommodation names.
- Use Inter for body copy, metadata, navigation, and uppercase eyebrow labels.
- Set body text around 15px with 1.6 line-height and a light weight.
- Use uppercase eyebrow labels around 11px with approximately 0.24em letter spacing.
- Keep headings light, narrow, and calm, with generous whitespace around them.

Layout:
- Use a max content width near 1280px with 24px mobile and 40px desktop side padding.
- Use asymmetrical 12-column layouts for architecture, wellness, dining, and booking content.
- Alternate warm light sections with full-bleed graphite scenes.
- Use large rectangular image crops with overflow hidden, object-cover, and a mixture of object-top and object-center positioning.
- Use restrained borders, thin rules, rectangular outline buttons, and only modest radii on forms and controls.

Image direction:
- Show monumental snow-covered peaks, alpine mist, dark pine forest, timber and glass architecture, quarried stone, cedar, wool, linen, open fire, thermal water, seasonal food, and quiet interiors.
- Daylight images should use snow white, mineral grey, muted pine, and soft blue. Dusk images should use deep indigo, graphite, timber brown, and warm amber window light.
- Keep people small within the landscape when present. Favor architectural and editorial hospitality photography over smiling stock photography.

Motion direction:
- Make scrolling the primary narrative control.
- Use a 260vh sticky hero where the mountain scene parallax shifts, the initial copy fades, a mist layer covers the image, and an ALPINE RETREAT wordmark appears through a background-clipped image treatment.
- Use soft scroll reveals for ordinary sections.
- Use a full-screen crossfade scene selector for Experiences.
- Use a pinned 400vh accommodation sequence where panels reveal by scrubbed clip-path.
- Use a bottom-up sticky takeover for the booking section.
- Keep motion slow, controlled, and cinematic. Prefer scrubbed transitions, power3.out reveals, long image crossfades, and subtle parallax over bouncy effects.

Responsive behavior:
- Collapse 12-column layouts to one column on small screens.
- Hide desktop navigation links and show a mobile menu.
- Keep full-bleed imagery and the same section order on mobile.
- Allow the Experiences tab row to scroll horizontally without showing a scrollbar.
- Stack the booking form and footer content vertically while preserving generous touch spacing.
- Respect reduced-motion preferences wherever possible.

Project Definition

Reconstruct a complete front-end website for Alpine Retreat, a contemporary high-altitude mountain hospitality retreat. The site should feel like a cinematic architectural travel journal: quiet luxury, warm snow, mist, stone, timber, glass, alpine pine, glacier grey, and slow editorial motion.

Use a single-page home route at /. Use a generic catch-all not-found route for every other path. Do not create separate routes for The Place, Experiences, Stay, Restore, Taste, or Book Your Stay. Those are sections on the same page connected by hash anchors.

The page is front-end only. Do not invent a database, room inventory system, payment system, CRM, concierge API, or reservation backend. The reservation form should have the same local success behavior described below unless a real integration is explicitly provided later.

Global Visual Direction

Design the website as an immersive mountain arrival. Start with a bright high-altitude landscape and a small timber-and-glass retreat nested below monumental snow peaks. Move through architecture, outdoor experiences, accommodations, wellness, seasonal dining, and finally a dusk booking scene.

The visual rhythm must alternate:
- light editorial sections using warm snow and mist white surfaces;
- full-bleed dark graphite scenes with white text and subtle black gradients;
- precise thin rules, uppercase eyebrow labels, soft low-contrast typography, and large atmospheric imagery.

Avoid rustic chalet clichés, saturated green outdoor-sport colors, glossy gold luxury styling, generic smiling hotel stock photography, heavy card grids, and fast bouncy animation.

Design System

Use the following token system:
- background-50: oklch(0.965 0.004 120), approximately warm snow #F3F4F0.
- background-100: oklch(0.930 0.004 150), approximately mist white #E7EBE8.
- background-950: oklch(0.135 0.008 160), a deep cinematic graphite.
- foreground-950: oklch(0.220 0.008 158), approximately graphite #202624.
- foreground-500: oklch(0.660 0.007 80), approximately natural stone #9D9B94.
- primary-500: oklch(0.440 0.030 155), approximately muted alpine pine #465851.
- accent-500: oklch(0.750 0.012 220), approximately glacier grey #AAB8BC.
- secondary-500: oklch(0.660 0.007 80), approximately natural stone #9D9B94.

Use the complete 50–950 shades from the supplied token system for borders, overlays, gradients, muted text, and alpha variants. Use warm snow and mist white for light sections, graphite and foreground-50 for dark sections, and alpine pine only as a restrained accent.

Typography:
- Use Fraunces at light weights for all display headings, the hero wordmark, and accommodation names.
- Use Inter for body text, labels, metadata, and navigation.
- Set body text around 15px, line-height 1.6, font-weight 300.
- Use an eyebrow label around 11px, uppercase, font-weight 500, and letter spacing around 0.24em.
- Use light headings around 30px on mobile and 42px on desktop; use around 52px for accommodation titles.
- The hero wordmark should use a responsive size close to clamp(64px, 19vw, 340px), line-height 0.86, and a tight editorial letter spacing.

Layout and Global Shell

Use a max-width near 1280px for normal section content. Use 24px horizontal padding on mobile and 40px on desktop. Use asymmetrical twelve-column grids from the md breakpoint upward.

Create a fixed top navigation:
- left: a small outlined circular landscape icon and the uppercase Alpine Retreat wordmark;
- center on desktop: The Place, Experiences, Stay, Restore, Taste;
- right on desktop: an outlined Reserve link pointing to #book;
- mobile: replace desktop links with a menu icon; open a vertical translucent panel containing the same links and Reserve.

When window scrollY is greater than 80, change the nav from transparent to a semi-transparent warm-snow background with backdrop blur, a subtle bottom border, and dark text. Before that threshold, use white text and a subtle top contrast.

Website Information Architecture

Render these sections in exactly this order:
1. Hero, id top.
2. The Place, id place.
3. Experiences, id experiences.
4. Stay, id stay. The visible section numbering begins at 04 in the source; do not invent a visible 03 section.
5. Restore, id restore.
6. Taste & Seasons, id taste.
7. Book Your Stay, id book.
