1. 设计基础 Prompt
============================================================

Create a premium private dental clinic design system for a brand called Aline dental.

Brand character:
- Calm, high-trust, precise, editorial, private, and quietly premium.
- Focus on natural results, clear treatment planning, digital diagnostics, and a low-pressure consultation experience.
- Avoid loud cosmetic dentistry advertising, exaggerated white smiles, generic hospital blue, or cold medical dashboard styling.

Color system:
- Use white #FFFFFF as the main page surface.
- Use cool page gray #F5F7F9 for quiet panels, image backplates, and closing conversion areas.
- Use brand cyan-blue #029DC9 for display accents, labels, progress lines, and primary CTAs.
- Use action blue #027EA3 for hover and interactive emphasis.
- Use soft cyan #DEF3F7 for selected states and the Booking & Contact background.
- Use pale yellow #FFF697 and soft yellow #FFFEF2 only as subtle secondary accents.
- Use near-black ink #0F1417 for headings and primary text, muted blue-gray #5C6670 for body copy, and faint gray-blue #8B959E for inactive labels.
- Use warm-gray borders such as #E5E7EB and keep contrast quiet but accessible.

Typography:
- Use Inter for navigation, body copy, controls, labels, facts, and form UI.
- Use Fraunces as the primary editorial serif for hero headings and major section headings.
- Use Fraunces italic or Instrument Serif italic for pull quotes and selected editorial phrases.
- Use compact uppercase eyebrow labels at 11px with 0.25em tracking.
- Use responsive display sizes from approximately 40px mobile to 64px desktop.
- Use relaxed body copy around 15–16px with 1.6 line-height.

Layout:
- Use a 1440px wide desktop container, an 1180px editorial container, and a 960px case-grid container.
- Use 24px horizontal padding on mobile and 40px on desktop.
- Use 96px mobile and 128px desktop standard section spacing; use 80px/96px for compact sections.
- Use 12-column desktop grids and single-column mobile stacks.
- Use 14px editorial media radii, 10px case tile radii, 6px control radii, and full pill CTAs.
- Keep the page airy, aligned to strong horizontal keylines, and avoid dense card dashboards.

Component language:
- Use cyan-blue filled buttons with white text and compact rounded corners.
- Use ink-outline buttons and underlined text links for secondary actions.
- Use thin gray rules for editorial lists, pricing rows, accordion rows, and information dividers.
- Use square case tiles, wide clinical image containers, and portrait patient images with object-top cropping.
- Use a fixed frosted-glass “Online Consultation” pill with a cyan breathing halo.

Image direction:
- Use believable premium dental photography: patients with natural smiles, dentists in consultation, digital scans, dental models, aligners, implants, veneers, and calm private clinic interiors.
- Prefer cool neutral professional light, soft gray or white environments, natural skin texture, and quiet compositions.
- Avoid overly retouched smiles, generic stock-photo poses, dramatic shadows, and saturated colors.

Motion language:
- Use long, controlled, editorial motion rather than bouncy UI animation.
- Use calm ease-in-out cubic navigation scroll, GSAP expo easing for image-to-overlay transitions, and 600–700ms image crossfades.
- Allow the Hero patient image to travel continuously from the Hero slot into the Concern Finder slot while the Hero copy fades and lifts.
- Use sticky scroll scenes for Practice and First Visit.
- Use restrained hover tilt for Results tiles, accordion expansion, case fly-to-detail transitions, a soft consultation halo, and a low-contrast particle ribbon.
- Respect reduced-motion where possible and provide a stable static layout when motion is disabled.

Reconstruct a complete premium private dental clinic website called Aline dental. The page should feel calm, precise, quietly luxurious, and high-trust. It should help a patient understand their concerns, explore real-looking outcomes, understand the clinic and first-visit process, compare treatments and indicative pricing, and open a consultation request drawer.

Project Definition

Build a responsive React and TypeScript website with Vite, React Router, Tailwind CSS, GSAP, GSAP ScrollTrigger, and a Canvas-based ambient particle layer. Implement the actual route structure:

- `/` — the complete Home page.
- `*` — a simple 404 placeholder page.

Do not create additional route pages for case detail, treatment detail, doctor detail, practice, or booking. Case details and concern details must open as full-screen overlays on the Home page. Booking is represented by a consultation drawer. Do not invent a backend, database, CRM, payment system, calendar availability, or real submission endpoint.

Global Visual Direction

- Make the clinic feel like a premium private dental practice focused on natural results, clear treatment planning, digital diagnostics, and calm consultation.
- Use a white page surface with cool pale-gray panels and a restrained cyan-blue brand accent.
- Brand cyan: #029DC9. Action/hover blue: #027EA3. Soft cyan: #DEF3F7.
- Use near-black ink #0F1417, muted text #5C6670, and faint text #8B959E.
- Use pale yellow #FFF697 and #FFFEF2 only as subtle secondary accents.
- Use Inter for all interface and body copy. Use Fraunces for large editorial headings. Use Fraunces italic or Instrument Serif italic for selected phrases and pull quotes.
- Use believable premium dental photography with cool neutral professional lighting, natural skin texture, real clinic equipment, digital scans, dental models, aligners, implants, and natural smiles.
- Avoid generic stock-photo dentistry, over-retouched smiles, saturated colors, loud gradients, and a cold hospital-dashboard aesthetic.

Design System

- Use a 1440px wide container with 24px horizontal mobile padding and 40px desktop padding.
- Use an 1180px editorial container for content-heavy detail, and a 960px max-width for the 3x3 Results grid.
- Use 96px mobile and 128px desktop vertical spacing for standard sections; use 80px mobile and 96px desktop for compact sections.
- Use 14px media radii, 10px case-tile radii, 6px compact controls, and full pill buttons when the component is explicitly a pill.
- Use thin gray rules for lists, pricing rows, accordion rows, and editorial dividers.
- Use compact uppercase eyebrows at 11px, medium weight, 0.25em tracking.
- Use responsive display type from approximately 40px mobile to 64px desktop, with a tight but readable editorial line-height.
- Primary CTA buttons use cyan-blue background, white text, a right arrow, and a hover state around #027EA3.
- Secondary actions use a thin ink border or an underlined text link.

Global Shell

Implement a fixed top navigation with a 64px mobile height and 72px desktop height. At the top of the page it is transparent; after scrollY exceeds 40px, switch to a white 95%-opacity background with backdrop blur and a subtle bottom border.

The navigation brand is a small inline SVG tooth-like mark followed by “Aline dental”. Desktop links are:

- Concern → `#concern`
- Results → `#results`
- Practice → `#practice`
- First Visit → `#first-visit`
- Treatments → `#treatments`
- Pricing → `#pricing`
- Contact → `#contact`

Add a desktop “Book a Consultation” button that opens the consultation drawer. On mobile, replace the links with a menu button; the expanded panel contains the same links and the consultation button.

Implement custom anchor scrolling rather than relying on browser instant jumps. Calculate the target with a 72px header offset, use an easeInOutCubic interpolation, and choose a duration between about 700ms and 1400ms based on distance. Update the URL hash with history.replaceState. Close the mobile menu after navigation.

Add a fixed “Online Consultation” floating button at bottom-right. It is a translucent white frosted-glass pill with 20px blur, a thin border, subtle shadow, a cyan chat icon, and a cyan radial breathing halo. The halo breathes over about 4.2 seconds. Hide the floating button while the drawer is open.
